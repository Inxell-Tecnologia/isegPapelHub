# Painel gerencial

Abra **Painel** para ver **cartões** com os números principais — total de arquivos,
total de colaboradores, espaço utilizado e percentual da cota — e **gráficos** de:

- quantidade de **arquivos por tipo**;
- **envios por mês**;
- **espaço utilizado versus disponível**.

Os números refletem o **alcance da sua unidade**. Administradores globais veem o
painel em escala global — ver [Unidades](unidades.md).
