# Ver quem acessou seus arquivos

Como **dono** de um arquivo, você pode abrir a **Auditoria** dele para ver **quem**
visualizou ou baixou, com **data e hora**. Você vê apenas os registros dos arquivos
que **você enviou** — não os de outros colaboradores.

Administradores têm um alcance mais amplo — ver
[Auditoria da unidade](../administrador/auditoria.md).
